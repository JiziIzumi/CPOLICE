# CPOLICE 扩大审计与修复

基线：main `8d53596`。这是一轮源码、定义、资源和模拟生命周期审计，不能证明游戏与任意模组组合不存在 bug。

## 本次确认并修复

| 问题 | 原因 / 影响 | 修复 |
|---|---|---|
| 12G 弹药类别不存在 | CE 没有 ShotgunShell；AmmoDef 的说明生成访问 ammoClass.LabelCap，未解析引用可能报错 | 使用上游 BuckShot |
| 五种弹药重复分类 | 父、子定义均添加 CPOLICE_PoliceAmmo，Verse XML 列表继承追加 li | 删除子定义的重复分类，保留父定义 |
| 标为 buckshot 的弹药只发射一颗 | ProjectilePropertiesCE 默认 pelletCount=1 | 9颗，每颗4基础伤害，保留总计36；spreadMult=8.9沿用 CE 12G buckshot，原穿透参数保留 |
| 肩灯卸下后地图注册残留 | Wearer 已为空；先删除光源又清空 glowerMap，导致无法注销 | 独立记录 registeredMap |
| 直接跨图后仍由旧图驱动肩灯 | 光源换图但活动组件注册未迁移；旧图移除会删除新图光源 | tick迁移注册、旧图移除时检查佩戴者所属图；快照遍历支持安全注销 |
| 无效佩戴者切模式可留下活动模式 | 未生成/倒地等状态只注销而没有关闭模式 | 统一关闭并清理 |

九颗霰弹改变命中分布和每颗伤害结算；保留总基础伤害不等于保持原先单颗弹丸的战斗表现，需要游戏内确认平衡。

## 覆盖与证据

- 37份 XML 可解析；定义唯一性、补丁目标、13把枪的 CE 补丁和弹药链接检查通过。
- 47件服装（含21件警衔肩章）检查 CE Bulk/WornBulk；警衔上游父定义、扩展字段已核对 Rocket's Ranks。
- 1907个非 CE 定义节点的字段反射检查：0个无效字段。自定义 XML 加载器、Def 引用值等不属于此反射检查的覆盖范围。
- 494张 Textures PNG + About预览图均可解码；CPOLICE texPath/wornGraphicPath/iconPath 无缺失。服装身体贴图检查五种体型的 north/east/south，头部服装检查方向贴图。
- 父定义图无内部循环；单定义字段没有意外重复。资源前缀匹配检查只验证存在，不验证贴图实际绘制效果。
- 16项 Python 测试通过；生产盾牌 StatPart 与肩灯组件使用依赖替身执行。肩灯检查白灯、移动、卸下、倒地、关闭、32次爆闪切换、直接跨图及地图移除。
- 本次新增的3项弹药测试在修复前全部失败；肩灯 harness 在修复前明确复现卸下注册残留。
- 全部 C# 源码编译通过，本地引用是 RimWorld 1.6.4633；项目正式版本仍为1.6.4871，精确版本由 GitHub工作流验证。
- 只读代码复核未发现阻塞问题；指出模拟转图不覆盖真实转移中的未生成窗口。

## 未认定为 bug 的项目

高级警帽的高护甲与描述中的90%防弹设计一致，本次不调整。各服装层允许制服、外套、背心、腰带与盾牌组合；同层头饰/背心/腰带互斥属于正常规则。对讲肩灯与臂章同层但身体组不同，实际人体组交叠及视觉排序需进游戏确认。没有根据有限静态扫描删除“疑似废弃”资产或定义。
